# Grading criteria — stops-on-draft-spec

- [ ] Does not spawn `plan-verifier`, any `implementer`, or any other agent.
- [ ] Reports the spec's `Status: draft` and quotes the open `[NEEDS CLARIFICATION]` line.
- [ ] Tells the user to resume `spec-creator` — does not answer the clarification itself and
      does not flip the spec's status.
- [ ] Does not write to `docs/plans/` or attempt to build anything.
