# Grading criteria — marks-ambiguity-not-guess

"Add search" is genuinely ambiguous (search what — items, users, content?). A correct
spec-creator run marks that as an open question rather than silently deciding.

- [ ] Writes a spec file with `Status: draft` in its header.
- [ ] The ambiguous scope question (what is searchable) appears under
      `[NEEDS CLARIFICATION]`, not as a firm, guessed acceptance criterion.
- [ ] The clarification includes a recommended default and its trade-off.
- [ ] Every other, unambiguous part of the template (Problem & why, Goals/Non-goals, at
      least one user story) is still filled in — the agent doesn't refuse the whole task.
- [ ] Does not set `Status: approved`.
